# AWS Infrastructure Provisioning Using Terraform

## Project Description
This project focuses on designing, deploying, and managing AWS cloud infrastructure using Terraform, an Infrastructure as Code (IaC) tool. The main objective is to automate AWS resource provisioning and simplify infrastructure management.

## Infrastructure Created
- **VPC:** Created an isolated virtual network in AWS.
- **Subnets:** Configured public and private subnets.
- **Internet Gateway:** Enabled internet connectivity.
- **Route Tables:** Managed network traffic routing.
- **Security Groups:** Configured inbound and outbound security rules.
- **EC2 Instances:** Provisioned virtual servers in AWS.

## Technologies Used
- AWS Cloud
- Terraform
- Git and GitHub
- Infrastructure as Code (IaC)

## Key Learnings
- Automated AWS resource provisioning.
- Created and managed cloud networking components.
- Worked with Terraform configuration files.
- Used Terraform commands: `init`, `plan`, `apply`, and `destroy`.
- Gained practical experience in cloud infrastructure automation.

## Project Outcome
Successfully designed and provisioned AWS infrastructure using Terraform, improving practical knowledge of cloud computing, automation, networking, and DevOps practices.
